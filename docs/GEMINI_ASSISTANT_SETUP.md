# تفعيل مساعد Gemini للزوار — أسيوط عقار

## الوضع الحالي
- واجهة المساعد الموجودة في `assistant.js` تحتفظ بإجابات الأسئلة المؤكدة والبحث العقاري المحلي.
- الأسئلة المفتوحة غير المغطاة محليًا تُرسل إلى Edge Function باسم `asyut-gemini`.
- مفتاح Gemini لا يظهر في ملفات المتصفح ولا يُحفظ داخل GitHub.
- وظيفة الاختبار منشورة على مشروع Supabase التجريبي فقط؛ لا يوجد أي تغيير على مشروع الإنتاج.

## إعداد المفتاح على مشروع الاختبار
1. أنشئ مفتاحًا من [Google AI Studio](https://aistudio.google.com/app/apikey).
2. افتح مشروع Supabase التجريبي ذي المرجع `wisnmlbefdrkcbbqvdlg`.
3. ادخل إلى Edge Functions ثم Secrets.
4. أضف اسم السر `GEMINI_API_KEY` والصق المفتاح في خانة القيمة.
5. لا تضف المفتاح إلى `config.js` أو أي ملف في GitHub أو رسائل عامة.

## الحماية وحدود النسخة التجريبية
- الوظيفة عامة لأن الزائر لا يحتاج إلى تسجيل الدخول.
- توجد حماية مصدر المتصفح، وحد أولي 8 طلبات للدقيقة لكل عنوان IP داخل نسخة تشغيل الوظيفة الواحدة، وحد للسؤال 600 حرف، ومهلة طلب.
- حد الذاكرة هذا ليس نظام rate limiting عالميًا؛ قبل تفعيل الإنتاج يلزم حد مركزي/بوابة حماية أو CAPTCHA ومراجعة الاستهلاك.
- ترسل الطلبات إلى Gemini مع `store: false`، ولا نرسل سجل المحادثة أو بيانات حساب المستخدم.
- استدعاءات Gemini API قد تكون لها تكلفة منفصلة عن اشتراك Google AI Plus.

## اختبار النشر
- لا يتم نشر المساعد على الموقع المباشر من هذا الفرع.
- لا يُفعّل الإنتاج قبل إضافة المفتاح ومراجعة حدود الاستخدام والحماية وموافقة صاحب المنصة.
