# ملحق الاختبارات الأمنية والتكاملية — 31 أكتوبر 2026

هذا الملحق يحدّث نتائج DRAFT_03 بعد اكتشاف قصور في النسخة الأولى من المسودة.

## 1) معالجة قراءة أعمدة الشركة

استُبدل منح SELECT الكامل على `company_profiles` بما يلي:
- `company_profiles_public`: View مخصص للبيانات العامة فقط، مع `security_invoker=true` و`security_barrier=true`، ويخضع لسياسات RLS.
- صلاحيات الأعمدة: `anon` و`authenticated` يستطيعان قراءة الأعمدة العامة فقط؛ لا توجد صلاحية SELECT على الجدول بالكامل.
- `layan_get_my_company_profile()`: يعيد سجل المستخدم الحالي فقط عبر `auth.uid()`.
- `layan_admin_list_company_profiles()`: يعيد طابور المراجعة فقط بعد التحقق من `layan_is_admin()`.
- لا يستطيع الزائر أو المستخدم المسجل قراءة `admin_notes` أو الأعمدة الداخلية مباشرة من الجدول.

## 2) تعديلات الواجهة على فرع المراجعة

- `companies.js`: دليل الشركات يقرأ من `company_profiles_public`، والمالك يقرأ ملفه عبر `rpc/layan_get_my_company_profile`. عمليات الكتابة تستخدم `Prefer: return=minimal` حتى لا تحتاج الواجهة إلى صلاحية SELECT على الأعمدة الداخلية.
- `admin.js`: طابور مراجعة الشركات يقرأ عبر `rpc/layan_admin_list_company_profiles`، بينما التحديثات تستخدم استجابات minimal.
- `company-profile.js`: صفحة الشركة تقرأ من `company_profiles_public`.
- لا تغيير على الهوية أو الشعار أو CSS.
