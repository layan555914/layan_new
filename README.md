# أسيوط عقار | ASYUT AQAR

منصة عقارية موجهة لمحافظة أسيوط، تجمع إعلانات العقارات والبيع والإيجار والتنازلات وسوق الخدمات ودليل الشركات.

## الصفحات الرئيسية

- `index.html`: الصفحة الرئيسية والعقارات والبحث وإضافة العرض.
- `property.html?id=<id>`: تفاصيل إعلان عقاري مستقل.
- `companies.html` و`company.html?id=<id>`: دليل الشركات وملف الشركة.
- `marketplace.html`: سوق الخدمات والأقسام الـ11.
- `my-listings.html`: إعلانات وطلبات الحساب.
- `favorites.html`: العقارات المحفوظة.
- `admin.html`: لوحة الإدارة.
- `reset-password.html`: استعادة كلمة المرور.
- `payment.html`: معلومات طلبات التمييز والخدمات التجارية؛ لا يوجد تحصيل إلكتروني معتمد في هذه الصفحة.

## التشغيل والإعداد

المشروع واجهة ثابتة (HTML/CSS/JavaScript) تستخدم Supabase لخدمات المصادقة وقاعدة البيانات والتخزين والوظائف الطرفية.

1. استضف الملفات مع الحفاظ على المسارات النسبية.
2. راجع `config.js` وتأكد أنه يحتوي عنوان مشروع Supabase ومفتاح Publishable فقط.
3. لا تضع Service Role أو أي Secret Key في ملفات المتصفح أو GitHub.
4. يجب أن يظل RLS مفعّلًا، وأن تكون صلاحيات كل جدول أضيق ما يسمح به استخدام الواجهة.
5. اختبر المصادقة والرفع والمراجعة والإشعارات في بيئة معاينة قبل النشر.

## التحقق الآلي

GitHub Actions يشغّل فحص صياغة JavaScript وTypeScript الخاص بـ Edge Functions، ويراجع الروابط المحلية وملفات PWA وCNAME. هذا فحص ساكن وليس بديلًا عن اختبار متصفح حي أو اختبار حساب مستخدم فعلي.

## قواعد العمل المعتمدة

- إضافة الإعلان العقاري العادي مجانية.
- لا توجد عمولة على إتمام البيع أو التنازل.
- يمكن طلب التمييز والمساحات الإعلانية والخدمات التجارية بالتواصل مع الإدارة؛ لا تُعرض أسعار أو باقات غير معتمدة ولا يتم تحصيل مبلغ تلقائيًا.
- جميع الإعلانات والملفات التي تتطلب مراجعة لا تظهر للعامة قبل اعتماد الإدارة.

## حالة الإصدار
